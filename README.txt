סנטר-Map - העלאה לגיטהאב מהאייפון

1. בקבצים (Files) - לוחצים ארוך על הזיפ ובוחרים "פתח" / "Uncompress". נפתחת תיקייה עם כל הקבצים.
2. בספארי: github.com -> הריפו שלך -> "Add file" -> "Upload files".
3. "choose your files" -> Browse -> נכנסים לתיקייה שנפתחה -> בוחרים את *כל* הקבצים (Select All) -> Open.
4. גוללים למטה -> "Commit changes".
5. Settings -> Pages -> Branch: main, תיקייה: / (root) -> Save. אחרי דקה הכתובת עובדת.

כל הקבצים כאן שטוחים (בלי תיקיות), כי הדפדפן בנייד לא יודע להעלות תיקייה.
